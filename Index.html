Entenda a linguagem FL

Como funciona
1

Cada letra vira um número

Usamos a posição da letra no alfabeto: A=1, B=2, C=3 … Z=26.

2

Números de 2 dígitos precisam de separador

Usamos o apóstrofo ' entre os números para não juntar tudo. Sem ele, 1'15'2'1 viraria 11521 e ninguém saberia onde cada letra começa.

3

Exemplos

Eai ➜ 5'1'9
aoba ➜ 1'15'2'1
FL ➜ 6'12
